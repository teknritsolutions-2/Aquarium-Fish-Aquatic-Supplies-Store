# Image Sources

The template loads photographic assets from [Unsplash](https://unsplash.com/) using `images.unsplash.com` delivery URLs. The image IDs used in `assets/js/catalog-data.js` and `assets/js/main.js` are the definitive source inventory.

Examples include photographic work delivered under these IDs:

- `photo-1546026423-cc4642628d2b` — reef/aquarium imagery
- `photo-1522069169874-c58ec4b76be5` — aquarium/fish imagery
- `photo-1535591273668-578e31182c4f` — aquatic imagery
- `photo-1497250681960-ef046c08a56e` — lush plant imagery
- `photo-1497436072909-f5e4be1713c0` — planted environment imagery
- `photo-1507525428034-b723cf961d3e` — ocean imagery

Unsplash source pages and photographer credits should be resolved and recorded during final client asset approval. The current photos are genuine photography, not AI-generated.

Important: several catalog records currently use representative aquatic photography because no client-supplied licensed species library was available. Before commercial launch, replace every fish-card image with a verified exact-species photograph, confirm the photographer/license, download optimized local copies, and record the original page URL plus attribution requirements here. Do not market the current representative images as exact specimens.
